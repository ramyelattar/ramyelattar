About
I am an Electrical Engineer building software around a simple idea:
> **AI should be useful on the user's own device — private, efficient, and available without depending on the cloud.**
My work sits at the intersection of:
⚡ Electrical construction and engineering workflows
🤖 Local LLM / ML inference
📱 Android applications
🖥️ Desktop applications
📄 PDF and document intelligence
🔐 Privacy-first / local-first architecture
🧩 Engineering automation and productivity
I focus on software that solves real operational problems rather than AI demos.

🤖 R2H AI Engine
Local-first Android AI runtime that isolates on-device inference in a dedicated process and exposes a controlled AIDL interface to R2H applications.
Includes native `llama.cpp`, ONNX / sherpa-onnx / NCNN integration, model lifecycle management, signature-protected IPC, and local-only telemetry.
`Android` · `Kotlin` · `C++` · `AIDL` · `llama.cpp` · `ONNX Runtime`

R2H Engineering Principles
```text
Local-first   > Cloud-required
Privacy       > Unnecessary collection
Useful        > Impressive demo
Efficient     > Oversized models
Reliable      > Fragile automation
Auditable     > Black-box behavior
Real-world    > Benchmark-only success
```
I optimize for realistic hardware and deployment constraints:
CPU-friendly inference
Quantized local models
Controlled memory use
Battery / thermal awareness on mobile
Local databases and durable state
Offline operation where practical
Secure IPC and native boundaries
Recoverable, production-oriented workflows
