## About Me

I am an **Electrical Engineer** building software at the intersection of engineering and **local AI**.

My focus is practical software that runs on the user's own device, keeps data private, reduces cloud dependence, and is useful in real engineering workflows.

**Main areas:**

- ⚡ Electrical construction and BIM-oriented automation
- 🤖 Local LLM / ML inference
- 🖥️ Rust + Tauri desktop applications
- 📱 Android applications with Kotlin / Java
- 📄 PDF and document intelligence
- 🔐 Offline-first and privacy-first architecture
